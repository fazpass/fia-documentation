# FIA Documentation (Android)

Documentation on how to use FIA Android SDK.

Choose the guide that fits your needs:

| Guide | Description |
|---|---|
| [Simple](README.Android.SIMPLE.md) | Bare minimum setup to get started quickly. Uses a premade OTP activity — no custom UI needed. |
| [Advanced](README.Android.ADVANCED.md) | Full SDK configuration including Miscall, HE, and Magic Link setup. Uses a custom-made OTP activity with manual auth type handling. |
